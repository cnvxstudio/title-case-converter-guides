# Suggest a Documentation or Example Correction

This repository documents Title Case Converter and provides practical English capitalization examples. Corrections should improve a user's understanding or reproduce an actual formatting issue.

For a proposed correction, include:

1. The documentation section or example ID.
2. Original text, selected format and style, and any preferred spellings.
3. Actual and expected output.
4. The style edition and a primary reference when the issue concerns a rule.
5. Why the correction matters in a real writing task.

Use small, anonymized examples. Do not submit private manuscripts, credentials, user data, or copied chapters from style manuals. Link to the relevant original rule instead.

Feature claims must match the current product. Do not add invented ratings, reviews, speed comparisons, user counts, or publisher endorsements. Product operators should disclose their relationship when making comparisons.

For support, use [support@titlecaseconverter.app](mailto:support@titlecaseconverter.app).
